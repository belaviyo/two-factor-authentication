# 2FA (Two-Factor Authentication)
Portable and Secure Two-Factor Authentication Using the Aegis Local Database.

### MCP Server
This extension can be used with coding agents such as OpenCode. Read [FAQs page](https://webextension.org/listing/2fa.html) for more info. Also check the [mcp.json](/v3/mcp/mcp.json) (LLM tool definition) file which defines available tools for an agent, using JSON-RPC 2.0 as the envelope and JSON Schema for input/output.
